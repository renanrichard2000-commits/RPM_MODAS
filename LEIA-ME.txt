BAHIA GRAPPLING CUP — SITE ESTÁTICO
===================================

ARQUIVOS
- index.html: conteúdo e estrutura do site
- style.css: visual responsivo para celular e computador

COMO VISUALIZAR
1. Extraia o arquivo ZIP.
2. Abra a pasta.
3. Dê dois cliques em index.html para abrir no navegador.

COMO PUBLICAR GRATUITAMENTE (GitHub Pages)
1. Crie uma conta em https://github.com/
2. Crie um repositório público, por exemplo: bahia-grappling-cup
3. Envie index.html e style.css para a raiz do repositório.
4. Abra Settings > Pages.
5. Em Build and deployment, escolha Deploy from a branch.
6. Selecione a branch main e a pasta /(root), depois Save.
7. Aguarde a publicação e use o endereço indicado pelo GitHub Pages.

ANTES DE DIVULGAR
- A data e o local ainda estão como "A definir".
- Não há formulário de inscrição ativo; o botão de inscrição leva à seção de contato.
- Troque o e-mail de exemplo contato@exemplo.com no index.html pelo endereço oficial.
- Substitua as imagens externas se desejar. Elas dependem de conexão com a internet e podem mudar ou deixar de estar disponíveis.
- Confirme regras, categorias, arbitragem, autorização de menores e segurança antes de abrir inscrições oficiais.

O site usa HTML, CSS e um pequeno script JavaScript para o menu móvel e o ano do rodapé.
